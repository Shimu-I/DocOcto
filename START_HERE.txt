DocOcto: quick start (Ubuntu)

1. One-time: sudo apt update && sudo apt install -y python3 python3-venv python3-pip
2. In this folder run:   bash run.sh
3. Open http://localhost:3000 in your browser and upload a PDF or Word file.
   Quick check runs by itself. Stop the server with Ctrl+C.
